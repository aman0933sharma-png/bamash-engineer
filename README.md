# Bamash Engineer

Civil site supervision desk for the NH-305 Hamirpur Bypass package.

Sign in, pick a designation, and the desk opens for that role:

- Bridge Engineer — bridges, culverts, underpasses
- Highway Engineer — embankment and pavement layers
- Site Engineer — daily diary
- Quality Engineer — RFIs and NCRs
- Safety Officer — hazard log
- Quantity Surveyor — measurement book

## Run

```bash
npm install
npm run dev
```

Works in the browser on phone, tablet, and computer.
